Primary interactive action element. Use `variant` to convey intent.

```jsx
<Button variant="primary" onClick={save}>Save Changes</Button>
<Button variant="secondary" leftIcon={<DownloadIcon />}>Export</Button>
<Button variant="danger" size="sm">Delete</Button>
<Button loading>Saving...</Button>
```

Variants: primary, secondary, ghost, danger, danger-ghost, outline, success, warning, nav
Sizes: sm (28px), md (32px), lg (38px), xl (46px)
